Judy's minimal academic portfolio starter

1. Open index.html in a browser to preview the website.
2. Replace YOUR_EMAIL, YOUR_GITHUB_URL, and YOUR_LINKEDIN_URL.
3. Replace the portrait placeholder with an image if you want one.
4. Put your CV PDF in this same folder and name it cv.pdf.
5. Edit the project and experience entries to match your preferred wording.

The site uses plain HTML and CSS; no framework or build step is required.
It can be hosted for free with GitHub Pages.
